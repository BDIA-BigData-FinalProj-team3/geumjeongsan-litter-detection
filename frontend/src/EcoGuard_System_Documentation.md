# EcoGuard 쓰레기 투기 모니터링 웹 대시보드 시스템 - 상세 기능 명세서

## 시스템 개요
EcoGuard는 CCTV 네트워크를 통해 쓰레기 투기, 화재, 낙석, 응급 상황을 실시간으로 감지하는 공무원 전용 모니터링 시스템입니다. 총 9개 화면으로 구성되어 있으며, 0px 모서리 반지름(KPI 카드 제외)을 적용한 통일된 디자인을 사용합니다.

---

## 1. 로그인 화면 (LoginScreen)

### 기능 및 UI 요소
- **로고 및 타이틀**: 
  - Shield 아이콘 (emerald-600 색상)
  - "EcoGuard" 텍스트 (emerald-900 색상)

- **입력 필드**:
  - **ID 입력 필드**: 
    - 플레이스홀더: "아이디를 입력하세요"
    - 포커스 시 emerald-500 테두리 강조
  - **PW 입력 필드**:
    - 플레이스홀더: "비밀번호를 입력하세요"
    - 비밀번호 표시/숨김 토글 버튼 (Eye/EyeOff 아이콘)
    - 포커스 시 emerald-500 테두리 강조

- **로그인 버튼**:
  - emerald-600 배경, 흰색 텍스트
  - 호버 시 emerald-700 배경 및 그림자 증가
  - 클릭 시 메인 맵 화면으로 이동

- **푸터 텍스트**: "관리자 전용 시스템입니다."

- **디자인**:
  - 중앙 정렬 레이아웃
  - 그라데이션 배경 (slate-50 to gray-50 to slate-100)
  - 0px 모서리 반지름 적용

## 2. 메인 맵 화면 (MainMap) - 가장 복잡한 화면

### 상단 헤더
- **좌측**:
  - 시스템 로고 (나무 아이콘)
  - "Geumjeong Sentinel AI" 타이틀
  - 햄버거 메뉴 버튼 (사이드바 토글)

- **우측**:
  - 사용자 정보: "홍길동님 환영합니다"
  - 로그아웃 버튼 (클릭 시 로그인 화면으로 이동)

### 메인 툴바 (상단 두 번째 줄)

#### 1. 햄버거 메뉴 버튼
- 사이드바 열기/닫기 토글
- 사이드바 상태에 따라 지도 영역 마진 조정

#### 2. 전체탐지 버튼
- **기능**: 모든 감지된 사고를 지도에 표시
- **활성화 시**: emerald-600 배경
- **마커 표시**:
  - 화재: 빨간색 원형 마커, Flame 아이콘
  - 낙석: 노란색 원형 마커, 산 모양 아이콘
  - 쓰레기: 초록색 원형 마커, Trash2 아이콘
- **우선순위**: 화재 > 낙석 > 쓰레기 (한 CCTV에 여러 사고 발생 시)

#### 3. 필터 드롭다운 (ChevronDown 아이콘)
- **드롭다운 메뉴 항목**:
  - **전체**: 그라데이션 원형 아이콘 (빨강-노랑-초록)
  - **화재**: 빨간색 원형 아이콘
  - **낙석**: 노란색 원형 아이콘
  - **쓰레기**: 초록색 원형 아이콘
- **기능**: 선택한 유형의 사고만 필터링하여 표시

#### 4. 실시간 CCTV 버튼
- **기능**: CCTV 위치를 지도에 핀 마커로 표시
- **마커 유형**:
  - **정상 CCTV**: 어두운 회색(#363636) 원형 + 삼각형 꼬리, Camera 아이콘
  - **점검필요 CCTV**: 주황색(#FF8C00) 원형 + 삼각형 꼬리, Wrench 아이콘
- **클릭 시**: CCTV 상세 정보 팝업 표시

#### 5. 헬기 착륙 가능 위치 버튼
- **기능**: 응급 헬기 착륙 가능 지점 표시
- **마커**: 빨간색 원형 배경에 흰색 "H" 문자, 흰색 테두리
- **위치**: 5개의 착륙 가능 지점 표시

#### 6. 낙석 센서 버튼
- **기능**: 낙석 감지 센서 위치 표시
- **마커**: amber-800 원형 배경, 지진파 아이콘, 흰색 테두리
- **위치**: 10개의 센서 지점 표시

#### 7. 알림 벨 (Bell) 아이콘
- **빨간색 AlertCircle 배지**: 새 알림 있음 표시
- **클릭 시**: 알림 드롭다운 패널 열림

### 알림 드롭다운 패널 (종 모양 버튼 클릭 시)

#### 탭 구조 (3개 탭)
1. **화재 탭** (빨간색 테마)
2. **낙석 탭** (노란색 테마)
3. **쓰레기 탭** (초록색 테마)

#### 각 알림 카드 정보
- **CCTV ID**: 클릭 가능 (해당 CCTV 강조 표시)
- **발생 시간**: "X분 전", "X시간 전" 형식
- **위치**: 등산로 1, 등산로 2 등
- **신뢰도**: XX% 표시
- **처리완료 버튼**: 
  - 클릭 시 알림 목록에서 제거
  - 지도에서 해당 CCTV 마커 제거

#### 알림 데이터 예시
- **화재**: 
  - CCTV-001, 등산로 1, 2분 전, 95% 신뢰도
  - CCTV-007, 등산로 2, 15분 전, 92% 신뢰도
  - CCTV-013, 공원중앙, 1시간 전, 89% 신뢰도

- **낙석**:
  - CCTV-008, 등산로 3, 5분 전, 88% 신뢰도
  - CCTV-018, 등산로 2, 12분 전, 91% 신뢰도
  - CCTV-002, 등산로 1, 30분 전, 86% 신뢰도

- **쓰레기**:
  - CCTV-003, 등산로 3, 3분 전, 82% 신뢰도
  - CCTV-009, 등산로 1, 8분 전, 85% 신뢰도
  - CCTV-015, 등산로 2, 20분 전, 80% 신뢰도

### 지도 영역

#### 배경
- 실제 지도 이미지 표시
- 지역명 라벨 오버레이:
  - 북문 (10%, 10%)
  - 등산로 1 (15%, 20%)
  - 등산로 2 (60%, 25%)
  - 공원중앙 (45%, 45%)
  - 등산로 3 (20%, 55%)
  - 남문 (75%, 75%)

#### 마커 인터랙션
- **호버**: 마커 크기 증가 (scale-110)
- **클릭 (전체탐지 모드)**: 탐지 상세 정보 팝업 표시
- **클릭 (실시간 CCTV 모드)**: CCTV 상세 정보 팝업 표시
- **알림에서 CCTV 클릭**: 해당 CCTV 강조 표시 (scale-150, 애니메이션)

#### 줌 컨트롤 (우측 하단)
- **+버튼**: 줌 레벨 증가 (최대 18)
- **줌 레벨 표시**: 현재 줌 레벨 숫자 (기본값 12)
- **-버튼**: 줌 레벨 감소 (최소 8)

### 팝업 창 (드래그 가능)

#### 1. CCTV 상세 정보 팝업
- **헤더**: emerald-600 배경, "CCTV 상세 정보", Move 아이콘 (드래그 핸들)
- **닫기 버튼**: X 아이콘
- **내용**:
  - 실시간 영상 표시 영역 (회색 배경, Camera 아이콘)
  - CCTV ID
  - 상태 (정상: 초록색 배지 / 점검필요: 주황색 배지)
- **드래그**: 헤더 영역을 드래그하여 위치 이동 가능

#### 2. 탐지 상세 정보 팝업
- **헤더**: emerald-600 배경, "탐지 상세 정보", Move 아이콘
- **닫기 버튼**: X 아이콘
- **내용**:
  - CCTV ID
  - 위치
  - 탐지된 사고 목록 (N건)
  - 각 사고별 정보:
    - 사고 유형 배지 (화재: 빨강 / 낙석: 노랑 / 쓰레기: 초록)
    - 탐지 시간
    - 신뢰도
    - **화재의 경우**: "자세히보기" 버튼 (Eye 아이콘)
- **드래그 가능**

#### 3. 알림 상세 정보 팝업
- **헤더**: emerald-600 배경, "알림 상세 정보", Move 아이콘
- **닫기 버튼**: X 아이콘, 닫을 시 CCTV 강조 해제
- **내용**:
  - CCTV ID
  - 위치
  - 탐지 유형 (화재/낙석/쓰레기 배지)
  - 발생 시간
  - 신뢰도
  - 영상 미리보기 (회색 배경, Camera 아이콘)
  - **문자신고 버튼**: 파란색, MessageSquare 아이콘
  - **다운로드 버튼**: emerald-600, Download 아이콘
- **드래그 가능**

#### 4. 화재 영상 상세보기 팝업
- **헤더**: 빨간색(red-600) 배경, Flame 아이콘, "화재 영상 상세보기"
- **닫기 버튼**: X 아이콘
- **내용**:
  - CCTV ID, 위치 (2열 그리드)
  - 발생시간, 신뢰도 (2열 그리드)
  - 대형 영상 영역:
    - 어두운 배경 (gray-900)
    - Flame 아이콘 애니메이션 (pulse)
    - "LIVE" 배지 (우측 상단, 빨간색)
  - **문자신고 버튼**: 파란색, MessageSquare 아이콘
  - **다운로드 버튼**: emerald-600, Download 아이콘
- **중앙 고정 위치** (드래그 불가)

### CCTV 마커 데이터 (총 20개)
- CCTV-001 ~ CCTV-020
- 각 CCTV는 고유한 위치 (x%, y% 좌표)
- 각 CCTV는 화재/낙석/쓰레기 중 하나 이상의 사고 감지 정보 포함
- 상태: 정상 또는 점검필요

## 특수 기능

### 메인 맵 - CCTV 강조 표시
- 알림 패널에서 CCTV ID 클릭
- 지도에서 해당 CCTV 마커 확대 (scale-150)
- 애니메이션 효과 (pulse)
- 다른 팝업 닫을 시 강조 해제

### CCTV 관리 - 전원 상태 규칙
- 전원이 off인 CCTV는 자동으로 상태가 "점검필요"로 변경
- 테이블에 빨간색 배지로 표시

### 다중 필터링
- 위치, 상태, 전원 필터를 동시에 적용 가능
- 검색어와 필터 동시 사용 가능
- 필터 적용 후 정렬 가능

### 팝업 드래그
- 모든 정보 팝업은 헤더를 드래그하여 이동 가능
- Move 아이콘으로 드래그 가능 영역 표시
- 화면 밖으로 나가지 않도록 제한 없음 (사용자 책임)
